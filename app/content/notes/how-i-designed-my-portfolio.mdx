# MDX Formatting Masterclass

This is a **Substack-style** MDX note designed to test *every formatting option* in your portfolio notes system.

It’s intentionally long so you can confirm:

- spacing ✅
- typography ✅
- code rendering ✅
- quote styling ✅
- table styling ✅

---

## 1) Why MDX is perfect for a portfolio

A portfolio “blog” does not need a full CMS.

In fact:

> **The best portfolio blog is the one you’ll actually update.**

MDX gives you the best of both worlds:

- Markdown simplicity
- Component power
